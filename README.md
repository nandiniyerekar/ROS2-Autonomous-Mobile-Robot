# ROS 2-Based Autonomous Mobile Robot (AMR)

## Project Overview
This project focuses on the design and development of a ROS 2-based Autonomous Mobile Robot (AMR) for intelligent indoor navigation and material handling. The robot is designed to autonomously transport materials in warehouse and industrial environments using LiDAR-based mapping, localization, path planning, and QR code-based material identification.

## Key Features
- Autonomous Indoor Navigation
- SLAM-Based Mapping
- AMCL Localization
- Navigation2 Path Planning
- Obstacle Detection and Avoidance
- QR Code-Based Material Identification
- Intelligent Material Handling
- ROS 2 Integration
- Raspberry Pi 5 Based Controller
